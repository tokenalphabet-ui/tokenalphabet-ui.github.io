Private key

A private key is a very large secret number. It controls one crypto address: the wallet uses it to sign every transaction that spends coins from that address.

The public key and the address are calculated from the private key, but the math only works in one direction. Anyone can see your address and send coins to it, and nobody can work out the key from it.

You rarely see private keys directly. Modern wallets generate them from your seed phrase, one per address, and keep them encrypted. If a wallet or website asks you to paste a private key, treat it as a scam until proven otherwise.
